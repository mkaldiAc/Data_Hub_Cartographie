Un seul fichier HTML, toutes les données intégrées

Les domaines, dépendances et jalons de couverture sont intégrés dans ce fichier HTML. Pour modifier le fichier lui-même, cliquez sur Enregistrer, puis sélectionnez le fichier HTML ouvert à l’écran (première utilisation de la session). Autorisez l’écriture dans Edge/Chrome. Les enregistrements suivants peuvent utiliser la même autorisation. Le fichier reste autonome et peut être envoyé à un collègue.

Enregistrer une copie crée une nouvelle version à envoyer ou à archiver, sans toucher au fichier original. La version active et les modifications non sauvegardées sont indiquées en haut de l’écran.

Document ouvert. Aucune modification non enregistrée.

Le navigateur n’identifie pas automatiquement le fichier qui a servi à ouvrir la page : lors de la première sauvegarde, choisissez explicitement ce même fichier. Si le fichier a été modifié ailleurs, l’enregistrement sera refusé pour éviter un écrasement. Utilisation recommandée : Microsoft Edge sur Windows. En cas de refus ou de navigateur non compatible, « Enregistrer une copie » utilise un téléchargement standard.

Fichier de données partagé

Choisissez un fichier JSON dans un dossier Teams synchronisé localement avec OneDrive et ouvert dans Edge ou Chrome. Les modifications sont alors enregistrées dans ce fichier lorsque vous cliquez sur « Enregistrer sur le dossier ». Les autres collaborateurs doivent recharger le fichier pour voir les changements.

Important pour le travail collaboratif

La synchronisation OneDrive n'est pas une base de données transactionnelle : deux personnes modifiant le même fichier en parallèle peuvent créer un conflit. Pour des saisies simultanées fiables et des droits centralisés, utilisez une application hébergée avec Microsoft Graph / SharePoint List ou une API sécurisée.

La publication d'un HTML dans les « Fichiers » Teams n'en fait pas automatiquement une application web consultable. Pour un accès via URL, hébergez les fichiers statiques sur un site interne (Azure Static Web Apps, par exemple), éventuellement intégré en onglet Teams.
