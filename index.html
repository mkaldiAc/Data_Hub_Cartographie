Fichier de données partagé

Choisissez un fichier JSON dans un dossier Teams synchronisé localement avec OneDrive et ouvert dans Edge ou Chrome. Les modifications sont alors enregistrées dans ce fichier lorsque vous cliquez sur « Enregistrer sur le dossier ». Les autres collaborateurs doivent recharger le fichier pour voir les changements.

Important pour le travail collaboratif

La synchronisation OneDrive n'est pas une base de données transactionnelle : deux personnes modifiant le même fichier en parallèle peuvent créer un conflit. Pour des saisies simultanées fiables et des droits centralisés, utilisez une application hébergée avec Microsoft Graph / SharePoint List ou une API sécurisée.

La publication d'un HTML dans les « Fichiers » Teams n'en fait pas automatiquement une application web consultable. Pour un accès via URL, hébergez les fichiers statiques sur un site interne (Azure Static Web Apps, par exemple), éventuellement intégré en onglet Teams.
